# Arun Venkataramanan’s portfolio

Live at [pyalwin.github.io](https://pyalwin.github.io/).

```sh
npm ci
npm run dev
```

Edit the project, experience, and writing entries in `src/app/content.ts`. The homepage is in `src/app/page.tsx`, and the interactive EngramDB example is in `src/components/RetrievalDemo.tsx`.

`npm run build` creates a static export in `out/`. The GitHub Pages workflow builds and deploys pushes to `main`.
